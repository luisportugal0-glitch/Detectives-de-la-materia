# Detectives de la materia — publicación con GitHub Pages

Esta carpeta contiene una actividad educativa estática (HTML, CSS y JavaScript) lista para publicar con GitHub Pages.

## Publicación desde el navegador (sin instalar programas)

1. Inicia sesión en https://github.com/ .
2. Pulsa **New repository** (Nuevo repositorio).
3. Nombre sugerido: `detectives-de-la-materia`.
4. Selecciona **Public** (Público) y crea el repositorio.
5. En el repositorio, elige **Add file → Upload files** (Agregar archivo → Cargar archivos).
6. Descomprime este ZIP en tu computadora y carga los archivos que contiene. Asegúrate de cargar `index.html` en la raíz del repositorio, no dentro de una carpeta adicional. Puedes cargar también `.nojekyll` y este README.
7. Pulsa **Commit changes** (Confirmar cambios).
8. Abre **Settings → Pages**.
9. En **Build and deployment**, selecciona **Deploy from a branch**.
10. En **Branch**, selecciona `main` y la carpeta `/(root)`; pulsa **Save**.
11. Espera unos minutos. En **Settings → Pages** aparecerá la dirección pública o el botón **Visit site**.

La dirección normalmente tendrá este formato:

`https://TU-USUARIO.github.io/detectives-de-la-materia/`

Sustituye `TU-USUARIO` por tu nombre de usuario real de GitHub. Esta dirección es solo un ejemplo de formato y no estará activa hasta publicar el repositorio.

## Antes de entregar

- Abre la URL publicada en una ventana privada/incógnito para comprobar que el docente puede acceder sin iniciar sesión.
- Prueba los botones, las respuestas correctas e incorrectas, el expediente final y **Volver a jugar**.
- Envía la URL pública, no la dirección del repositorio ni el archivo ZIP.
- No incluyas datos personales o información sensible en el repositorio público.

## Sobre la actividad

La actividad funciona en el navegador y no requiere servidor ni base de datos. Las respuestas y el progreso se mantienen durante la sesión; no se guardan ni se envían automáticamente al docente. Si la consigna requiere registrar resultados individuales, habrá que añadir un mecanismo de entrega o adaptar la actividad a una plataforma que lo permita.
